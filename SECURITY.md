## Reporting a Vulnerability

The Fillify team takes the security of its users and code very seriously. If you believe you have found a security vulnerability in this repository, please do not disclose it via a public GitHub issue.

### How to Report

Please report security issues privately by using one of the following methods:

1. **GitHub Private Vulnerability Reporting**: If enabled on this repository, submit an advisory via the **Security** tab -> **Report a vulnerability**.
2. **Direct Contact**: If private reporting is not available, contact the project maintainers directly via their primary contact channels.

### Information to Include

To help us validate and triage the issue quickly, please include:

- A clear description of the vulnerability and its potential impact
- Step-by-step instructions or proof of concept demonstrating how to reproduce the issue
- Browser environment details (browser engine, version, operating system)
- Any proposed mitigations or remediation patches if available

### Response Timeline

- **Acknowledgment**: Within 48 hours of initial receipt
- **Assessment & Triage**: Within 5 business days
- **Fix & Public Advisory**: Coordinated release following patch validation
